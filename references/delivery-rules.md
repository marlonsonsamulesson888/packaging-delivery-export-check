# 交付规则默认值（本厂现行口径，可配置）

| 项目 | 默认 | 说明 |
|---|---|---|
| 外发件数 | 2：分层转曲 AI + 带刀线 JPG | PDF 只作厂内检查中间件，不外发；说明和检查证据不算设计文件 |
| 工作版 | 未转曲可编辑 AI 留厂 | 只在厂内改稿用，不外发 |
| JPG 范围 | 整个画板 | 不裁到成品线、不只导出可见区域 |
| JPG 刀线 | 必须显示 | 让客户/印厂对位；JPG 上的刀线不是印刷内容 |
| JPG 分辨率 | 300ppi | 横像素 = 宽 mm ÷ 25.4 × 300，纵像素同理，四舍五入并记录计算值和实测值 |
| 像素容差 | ±1px | 超出即重新导出 |
| 只改 DPI 标签 | 不算 | 像素不够就是不够 |
| AI 转曲 | 字体资源 = 0 | 文件名写“转曲/CURVAS”不算数；字体 0 也要逐元素检查描摹残渣 |
| AI 真伪 | 有 Illustrator 私有数据 | PDF 改扩展名不收 |
| 文件命名 | 客户_产品_盒型尺寸_版本_日期 | 按项目习惯，不用“最终版”“最新” |

## 不在本技能里做
出血、安全距、CMYK 与总墨量、字号线宽、位图有效 ppi、条码——交印前技术复核技能。
